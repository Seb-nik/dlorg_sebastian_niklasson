# Download Organizer

## Download the zip

Click on "<> Code" and choose "Download as ZIP"

Extract it wherever is convenient


## Run the script

Double click script to start. You may need to right click and choose "Run as a program"

This should open a terminal with the text:

"Setting up watches.
Watches established."

This means that the script is running


## What does the script do

It checks the Downloads folder for directories called zip, videos, text, pdf, music, images, documents and other and creates them if they don't

When the script is running, every file that is added to the Downloads folder will automatically be sorted to avoid clutter.
